## 📖 Descrição do Projeto

Este repositório foi desenvolvido como atividade avaliativa prática com o objetivo de
demonstrar, na prática, o fluxo de trabalho colaborativo utilizando **Git** e **GitHub**.
Ao longo do projeto, registramos e organizamos os principais conceitos estudados em aula,
simulando um cenário real de colaboração entre dois desenvolvedores em um mesmo repositório,
sem conflitos de merge.

## 🎯 Objetivos

- Praticar o versionamento de código com Git
- Colaborar em um repositório remoto no GitHub
- Registrar o conteúdo teórico estudado em aula
- Adotar boas práticas de commits (Conventional Commits)

## 🗂️ Tópicos de Estudo (Git & GitHub)

| Tópico | Descrição |
|---|---|
| `git init` | Inicializa um repositório Git local |
| `git clone` | Clona um repositório remoto para a máquina local |
| `git add` | Adiciona arquivos à área de staging |
| `git commit` | Registra as alterações no histórico local |
| `git push` | Envia commits locais para o repositório remoto |
| `git pull` | Atualiza o repositório local com mudanças remotas |
| `git branch` | Gerencia branches (ramificações) |
| `git merge` | Une alterações de branches diferentes |
| `git log` | Exibe o histórico de commits |
| `git status` | Mostra o estado atual dos arquivos |
| Conventional Commits | Padrão de mensagens de commit (`feat:`, `fix:`, `docs:`, `chore:`) |
| Colaboradores no GitHub | Como adicionar e gerenciar acesso de colaboradores |

Veja o detalhamento completo em [`tabela-de-estudos.md`](tabela-de-estudos.md).
